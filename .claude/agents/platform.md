## ثوابتٌ لا تُكسر

- **لا تُحذف هجرة، ولا يُعاد بناء المخطط.** وسلسلة الهجرات مكسورةٌ تاريخيًّا للقواعد
  الفارغة عمدًا — لا «تُصلَح» بإضافة السمات، فذلك يكسر الإنتاج.
- **ترتيب الإنشاء**: الجدول يُنشأ بعد ما يشير إليه. وقاعدةٌ قائمة لا تكشف الخلل —
  الجدول فيها من قبل — فيمرّ صامتًا إلى يوم استعادةٍ بعد كارثة. `npm run verify:schema`
  يبني من الصفر وهو ما يمسك هذا، ويجب أن يبقى في CI.
- **`CREATE TABLE IF NOT EXISTS` لا يضيف عمودًا إلى جدولٍ قائم** — العمود الجديد
  يحتاج `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` وإلّا مرّ الأمر صامتًا في الإنتاج.
- **لا Blobs في PostgreSQL**: الوصف في القاعدة والجسم على القرص. نسخةٌ تستغرق ساعة
  نسخةٌ لا تُؤخذ.
- **`audit_log` يُكتب ولا يُعدَّل ولا يُحذف منه** — مُحاطٌ بمشغّلات ترفض ذلك من
  القاعدة نفسها. ولا تُبنى عليه استنتاجاتٌ أوسع ممّا يشهد به: فعلٌ يُسجَّل قبل
  اكتمال بثّه لا يشهد بأنّ البثّ اكتمل، وفعلٌ يتشارك اسمَه مسارانِ لا يشهد بأيّهما وقع.
- **الفخّ الحرفيّ**: SQL في `lib/db.ts` داخل قالبٍ نصّيّ — علامةُ ` واحدة في تعليق
  تُغلق النصّ وتكسر الملف. وقع مرّتين.
- **بوّابةٌ تُفتح عند عجزها ليست بوّابة**: فحصٌ لا يستطيع أن يجري يسقط برمزٍ يميّزه
  عن الفشل الحقيقي، ولا يمرّ صامتًا.

· `npm run verify:http` · `npm run build`. وأثبت كل حارسٍ بإعادة العطب.
